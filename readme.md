# Automação de Cadastro de Produtos com Python

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante uma aula prática do Hashtag Programação com o objetivo de automatizar o cadastro de produtos em um sistema empresarial.

A aplicação realiza a leitura de uma base de dados contendo centenas de produtos e faz todo o preenchimento do sistema automaticamente, cadastrando informações como:

* Nome do produto;
* Descrição;
* Valor;
* Observações.

O objetivo do projeto foi colocar em prática conceitos de automação de processos utilizando Python, reduzindo tarefas repetitivas e aumentando a produtividade.

## 🚀 Tecnologias utilizadas

* Python
* Pandas
* PyAutoGUI
* Time

## 📚 Conceitos aplicados

* Leitura e manipulação de dados com Pandas;
* Automação de teclado e mouse com PyAutoGUI;
* Controle de tempo entre ações utilizando Time;
* Lógica de programação;
* Organização do código;
* Automação de processos repetitivos.

## ▶️ Como executar

1. Clone este repositório.
2. Instale as dependências necessárias.
3. Configure o ambiente conforme o sistema utilizado.
4. Execute o arquivo principal do projeto.

> **Observação:** Como a automação interage diretamente com a interface gráfica do computador, pode ser necessário ajustar coordenadas, tempos de espera e resolução da tela para que o funcionamento seja adequado ao seu ambiente.
